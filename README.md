# Neural Apply

A lightweight job portal for AI and Machine Learning roles.

## What it does
- Upload resume file (stored only in browser session).
- Fetches latest internet job listings from public APIs.
- Filters for:
  - AI/ML-only roles
  - STEM
  - H1 sponsorship
  - GC / permanent resident
- "Submit to All" opens apply links in bulk.

## Run
Open `index.html` directly in browser, or run a static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
